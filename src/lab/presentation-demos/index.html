Component Presentation Spec v0.1

Warm tools for serious learning.

Four visual demonstrations of the same Foundry presentation system: paper-and-ink warmth, restrained hand-drawn marks, one focused task, and the learner’s work at the center.

DISCRIMINATE

Classification Workspace

Cut-paper cards, quiet drop zones, and feedback that annotates the learner’s sorting instead of replacing it.

PREDICT + MANIPULATE

Causal Explorer

Prediction stays visible while the learner changes a variable and compares expectation with observation.

INTERPRET

Data Investigation

The graph remains dominant; evidence is selected, circled, and turned into a concise claim.

CONSTRUCT

Mechanism Builder

A calm canvas with a tiny tool tray, hand-drawn arrows, and preserved learner work during feedback.
